## 🚀 การนำไปใช้งานและเผยแพร่บน GitHub Pages

เว็บไซต์นี้เป็นแบบ **Pure Static** จึงสามารถเปิดใช้งานหรือ Deploy ได้ทันทีโดยไม่ต้องติดตั้งเครื่องมือใด ๆ:

1. **เปิดบนเครื่องคอมพิวเตอร์:**
   - ดับเบิลคลิกไฟล์ `index.html` เพื่อเปิดใช้งานบนเบราว์เซอร์ได้ทันที
2. **อัปโหลดขึ้น GitHub Pages:**
   - อัปโหลดไฟล์ `index.html`, `style.css`, และ `script.js` ไปที่ Repository บน GitHub
   - ไปที่ **Settings** > **Pages**
   - เลือก Branch `main` (หรือ `master`) โฟลเดอร์ `/ (root)` แล้วกด **Save**
   - เว็บไซต์จะออนไลน์พร้อมใช้งานทันที
